Why NexusAgent

Small core, honest features

Everything below is contract-tested; the public surface is pinned by CI (ADR 0010).

📦

Zero runtime dependencies

The whole core is the Python standard library. pip install nexusagent-runtime pulls nothing else.

🔁

Bounded autonomous tool loop

Providers request tools; the agent executes and re-invokes them, bounded by max_iterations.

🧠

Conversation memory

Opt-in Memory: in-process FIFO or persisted SQLiteMemory — remembered turns compose into each prompt.

🌊

Streaming

SSE text deltas from OpenAI, Anthropic and Gemini adapters, sync and async, through on_delta.

⚡

Async mirror

AsyncAgent/AsyncRuntime mirror every sync contract; sync providers keep working via a thread bridge.

🛡

Automatic retries

Transient HTTP failures retried with exponential backoff, full jitter and Retry-After support.

🔒

Stable public API

SemVer over the full root surface; a CI-pinned test fails on any accidental removal, rename or silent addition.

✅

Quick start

Five lines to a working agent

quickstart.py — offline by default
from nexusagent import create_application_runtime

runtime = create_application_runtime()   # offline `fake` provider

result = runtime.run("Hello NexusAgent")
print(result.output)                     # fake response: Hello NexusAgent
print(runtime.execute_tool("calculator", "2 + 3"))  # 5
memory.py — context across restarts
from nexusagent import SQLiteMemory, create_runtime

memory = SQLiteMemory("session.db", max_turns=50)
runtime = create_runtime(memory=memory)

runtime.run("My name is Sara")
memory.close()                           # a later process…

memory = SQLiteMemory("session.db", max_turns=50)
runtime = create_runtime(memory=memory)
print(runtime.run("What is my name?").output)
# the model still knows — the file remembers
